# kloudlite-sdk

Client libraries for Kloudlite.

- [`python/`](python/): `pip install kloudlite`, models and datasets from Hugging Face or the Kloudlite hub.

Python release: bump `version` in `python/pyproject.toml`, then push a tag `py-v<version>`. The
`pypi` workflow tests, builds and publishes through PyPI trusted publishing.
